# Contributing Guidelines

Thank you for considering contributing to the **Church Management System (CHMIS)**!

## How to Contribute

1. **Fork the Repository**
2. **Create a Feature Branch**
   ```bash
   git checkout -b feature/amazing-feature
   ```
3. **Commit your Changes**
   - Follow clean commit message guidelines (e.g., `feat: ...`, `fix: ...`, `docs: ...`).
4. **Push to the Branch**
   ```bash
   git push origin feature/amazing-feature
   ```
5. **Open a Pull Request**

## Code Standards
- Ensure all Java code is properly formatted.
- Write unit tests for new features.
- Verify `./mvnw test -Dspring.profiles.active=test` passes before submitting PR.
